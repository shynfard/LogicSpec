# Changelog — LogicSpec for VS Code

The extension is versioned in lockstep with the LogicSpec toolchain; the full
project history lives in the repository's root `CHANGELOG.md`.

## 0.14.0 — 2026-08-26

- Version aligned with the LogicSpec toolchain (previously the extension
  carried its own 0.5.x line; 0.5.16 was the last of it).
- Marketplace listing gains this changelog and a bundled license.

## 0.5.x — 2026-08-10 … 2026-08-25

The 0.5 line grew the extension from inline diagnostics and a static Mermaid
preview into the current experience: an interactive React Flow canvas with
hover tracing and actor colors, movable nodes, zoom/pan, clickable diagrams,
a step inspector drawer with cross-file links, an in-panel view switcher, a
live workspace graph, the embedded dashboard, a full-screen feature-detail
shell, denser feature lists, and dark-mode fixes. See the root changelog for
the per-release breakdown.
